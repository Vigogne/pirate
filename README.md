# 海盗湾 · 3v3 海战 MOBA

俯视角 2D 海战 MOBA。**上方敌方基地 / 下方我方基地**，各自动生成大量护航舰互相进攻；
每方还有 **一塔 / 二塔** 两座防御塔 —— **塔不拆光，基地免伤**。
双方各有 **3 艘英雄战船**（我方：旗舰号由你操控 + 2 名 AI 队友；敌方 3 艘 AI），
英雄与其他战船同权限：4 个炮位、船体/风帆/装甲模块、自动打怪→赚金币→自力升级。
**摧毁敌方基地获胜。**

## 运行

**双击 `index.html` 即可游玩**（纯前端、无服务器依赖）。

- 画面为**高质量像素风（HD-2D）**，图形来自本地 **PNG 素材**（`assets/atlas.png` + `assets/manifest.js`），
  由 `_gen/` 工具离屏生成；若素材缺失，游戏自动回退到内置绘制（功能不受影响）。
- **2D 骨骼动画**（`js/rig.js`）：船体/帆/旗、章鱼八条触手（每根两节骨骼链）、鲨鱼尾、
  塔炮塔等部件挂在骨骼上，由程序逐帧驱动姿态（帆随航行鼓风摆动、触手行波、尾鳍摇摆）；
  受击特效使用独立"白描边"素材 + 星光，不改变原图。
- 🧭 **方向键 / WASD** 航行 —— 船身会朝移动方向自动转向（不是平移）
- 📱 **手机版**：在画面上**按住拖动 = 虚拟摇杆**（模拟量），右上角按钮：装备 / 修船 / 🎯射程 / ⏸暂停 / 静音；横屏体验最佳
- **按住 CTRL**（或点 🎯 按钮）显示旗舰号四个炮位各自的武器射程（不同颜色）
- 屏幕左下角有 **武器冷却面板**：4 个装备图标实时显示冷却进度与强化等级
- 右侧**可折叠战报栏**：各船「击杀英雄 / 击杀小兵 / 死亡」分开统计、复活倒计时、各船金币
- **击沉英雄**时屏幕中央弹出大字播报（敌方阵亡金色 / 我方阵亡红色）
- SPACE 暂停 · **P** 船坞装备坞 · **M** 静音 · **C** 作弊刷钱
- 右上「⚙️ 装备」随时换装、升级、修理旗舰号；船坞内有**作弊选项**（一键刷钱 / 自动刷钱）
- 地图是一张 **4 屏高**的大海图，陆地岛群**分割战场、阻挡船只**，相机跟随旗舰号，
  右侧**小地图**显示基地/防御塔/敌我舰/视口

## 如何修改

### 武器（`WEAPONS`）
每个武器一个对象：`damage/rate/range/speed`、`splash`（溅射半径）、`pierce`（贯通）、
`count`（单次弹数）、`arc/arcH`（抛物弹）、`grow`（每级强化倍率）。
风格：`cannonball/twinball` 加农与二联装、`mortar` 臼炮、`grenade` 榴弹、
`harpoon` 鱼叉、`torpedo` 鱼雷、`bullet` 机枪、`flame` 喷火。

### 阵营 / 基地 / 塔 / 全局（`TEAM` / `BASES` / `TOWERS` / `TOWER_DEF` / `MOBA`）
- `TOWERS`：每方一塔/二塔的位置与等级；`towerHp(tier)` 决定耐久；`TOWER_DEF` 决定塔的
  伤害/射程/攻速/拆塔赏金。塔未拆完前 `Game.damageBase` 会被护盾挡住。
- `MOBA.startGold / heroBounty / baseHp / minionInterval / minionCap / heroRespawn /
  engageRange / defendRange / turnSpeed / cheatGold` 各字段注释里都有说明。
- `minionInterval`、`minionCap` 控制**小兵刷新数量**。

### 陆地（`LAND`）
每项 `{ shape:'ellipse', x, y, rx, ry, base? }` 既是**绘制**也是**碰撞**（`game.landResolve`），
改这里即可重新排布战场地形；三条兵线（LANES）要保持畅通。

### 英雄 / 舰船（`HERO_SLOTS` / `HULLS` / `SAILS` / `ARMORS`）
六个英雄默认 4 炮位（**兵线镜像对称**保证公平），船部件四档升级。
AI 行为（守基地/守塔/追击/撤退/推塔/自动升级）在 `ship.js` 的 `_aiThink / _aiGrow` 调整。

### 护航舰（`MINIONS`）
`hp/speed/money/damage/range/rate` —— 改数量用 `MOBA.minionInterval`、`minionCap`。

> 加新武器/护航舰：在对应对象加条目并登记到 `WEAPON_ORDER` / `MINION_ORDER` 即可。

## 手机游玩 / 部署到服务器

游戏是**纯静态前端**（无后端、无依赖、路径全相对），上传即可在手机浏览器打开：

1. 上传以下文件到任意静态服务器（宝塔/nginx/Apache/OSS/GitHub Pages 等）：
   `index.html`、`version.json`、`css/`、`js/`、`assets/`（`_test/`、`_gen/`、`_deploy/` 可不传）
2. 手机浏览器访问 `https://你的域名/` 或 `/index.html` —— 建议**横屏**游玩
3. 手机适配说明：
   - **视口自适应**：横屏/竖屏都全屏（视口宽高按屏幕比例自动计算，相机 X/Y 双向跟随）
   - **虚拟摇杆**：在画面上按住拖动即是移动方向（模拟量，带死区）；**双指捏合缩放视野**
   - HUD 按钮：技能 / 道具×2 / 装备 / 修船 / 🎯射程 / 📍指令 / ⏸暂停 / ⚙️设置
   - HUD/战报栏/船坞在小屏下自动换行收缩；已禁用页面缩放/双击放大
4. 局域网自测：`npx serve .` 或 `python -m http.server 8000`，手机与电脑同一 WiFi 访问电脑 IP 端口

### 部署后玩家自动拿到最新版（防缓存）

玩家点开链接**不会卡在旧版本**，三层保障：

1. **构建版本戳**：发布前跑一次
   ```bash
   node _gen/run.js      # 重新生成素材（改了美术才需要）
   node _gen/stamp.js    # 生成版本号：给 index.html 所有本地资源加 ?v=版本号，并写 version.json + js/version.js
   ```
2. **运行时自检**（`js/main.js` `checkVersion`）：启动时与每 5 分钟用 `no-store` 抓 `version.json`，
   与本页 `GAME_VERSION` 不一致 → 清理 Cache Storage → 提示后带 `?v=新版本` 强刷（30 秒内只刷一次防抖）。
3. **服务器缓存头**（关键）：把 `_deploy/` 下对应文件放到站点根目录 ——
   Nginx 用 `nginx.conf.txt`、Apache 用 `.htaccess`、Netlify/Cloudflare Pages/Vercel 用 `_headers`；
   规则是 **`index.html` 与 `version.json` 不缓存**，`js/`、`css/`、`assets/` 长期缓存（URL 带版本号）。
   详细说明见 **`_deploy/README.md`**。

> 有 CDN 时记得把 `index.html` / `version.json` 也设为不缓存（或 60 秒内短 TTL），否则 CDN 会继续发旧页面。

## 性能（移动端优化）

用 `node _test/perf-audit.js` 能量出每帧的绘制调用数 / 填充面积 / 描边次数 / DOM 写入。
优化前后（1280×900 视口、48 小兵、真实图集路径）：

| 指标（每帧） | 优化前 | 优化后 |
|---|---|---|
| 水面填充面积 | 58.9 M px | **4.5 M px** |
| 整帧填充面积 | 64.8 M px | **5.7 M px** |
| 整帧绘制调用 | 4870 | **1045** |
| 整帧描边次数 | 1518 | **172** |
| UI DOM 写入 | 约 12 次/帧 | **≈0 次/帧** |

做法：
- **水面只在可见矩形内绘制**（世界 1920×4500，一屏只占约 1/8）；渐变对象缓存复用；
  缓涌波带由"从波带线填到世界底部"改为定高条带（单层面积降约 10 倍）。
- **浪沫/波光改用世界锚定的哈希网格**：视口内密度恒定、位置稳定、天然剔除屏外。
- **视口剔除**：小兵 / 英雄 / 塔 / 海兽 / 宝箱 / 水雷 / 毒云 / 弹体 / 粒子 / 航迹只画屏幕内的。
- **航迹分桶合批 + 屏外剔除**；低画质单桶单线、中画质仅单侧 V 边线。
- **UI 脏检查**：数值未变不写 DOM；战报栏 4Hz 节流（原来每帧 6 行 innerHTML）。
- **分辨率自适应**：像素比上限 低=1 / 中=1.5 / 高=2；**移动端默认中画质且上限 1.5**（像素量减半）。
- **帧率自愈**：连续 2.5 秒低于 42fps 自动降一档画质（只降不升；手动改过画质后不再自动调整）。


## 机制一览

- 三条兵线（LANES）自动出船推进、遇敌交战；**每方一塔两座（左右）+ 二塔两座（左右）**，
  一塔全拆前二塔无敌（蓝色护罩），二塔全拆前基地免伤。
- **野区海兽 Boss（各一只，带特色巢穴）**：深海章鱼 🐙 盘踞**礁石溶洞**（石环+螺旋壳+旋涡气泡）、
  猎鲨王 🦈 巡弋**沉船残骸**（断船骨帆+血湾涟漪）；程序化动画（章鱼触手行波、呼吸、眨眼、追击竖瞳）。
  击败得赏金并**解锁特殊装备**（墨汁炮 / 鲨牙弩）；60 秒后重生；小地图紫色圆点标注。
- **五种全异船体**（各有专属技能，均可强化至 Lv5，旧船体原价卖回）：
  旗舰型（双桅帆船·💨疾风冲刺）、铁壁型（蒸汽铁甲舰·🛡️减伤75%）、疾风型（三角帆快艇·⚡速射+55%）、
  破浪型（黄铜撞角冲撞舰·🌊破浪冲撞）、生物型（章鱼身+鲨鱼头，击败两大海兽解锁·🐙深海狂暴）。
- 英雄武器自动索敌开火（4 槽独立、射程各异）；AI 英雄会守塔、追击、低血量撤退、
  用自己赚的金币自动升级武器与模块（与你同规律）。
- 英雄被击沉 9 秒后在己方基地重生；靠近己方基地快速修理（双方对称，带修理动画光环）
- 手动「修船」有 12 秒冷却；更换武器时**旧武器按原价卖回**（+金币）
- 击杀赏金：护航舰 15/25，防御塔 80，英雄 90，野区 Boss 200/300；对塔有 1.6 倍围攻加成
- 击杀英雄屏幕中央播报；右侧战报栏分「击杀英雄/击杀小兵/死亡」统计。
- 船会撞上陆地岛群与塔石台（会沿陆地滑行，需绕行兵线/水道）。
- 所有船/鱼雷都有沿真实路径连续延伸的 V 形泡沫尾迹（随体型缩放、转向不断线、位移异常不伪造）。
- 炮管方向 = 发射方向，炮口火光/弹体从炮管末端飞出；武器等级用**炮管材质色 + 座圈环珠**区分。
- 武器购买界面标出**价格与可购性**（买得起的绿色、买不起的变灰、未解锁的显示 🔒 与击败目标），
  换装时旧武器按原价卖回；船坞面板右上新增 **✕ 关闭按钮**。
